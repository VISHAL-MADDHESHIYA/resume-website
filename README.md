# Simple Resume Website

A responsive single-page resume website built using HTML5 and CSS3 as part of my Web Development Internship - Task 3.

## 📌 About the Project

This project is a professional online resume website that presents my:

- Profile
- Education
- Technical Skills
- Internship Experience
- Projects
- Contact Information

The website is designed to be simple, professional, responsive, and easy to scan.
